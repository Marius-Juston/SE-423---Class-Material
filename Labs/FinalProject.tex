\MakeAssignmentTitle

Your final robotics project will be completed in \textbf{teams of 4 or 5 students}. This capstone assignment is an opportunity to showcase your skills in robotics, control systems, sensing, and software integration. Each team must \textbf{propose and execute a unique robotics project}, designed, built, and tested over the next \textbf{three weeks}.

The first week will focus on your \textbf{project pitch}, where you will define your goals, assign roles, and begin your system design. This will be followed by two weeks of development, testing, and iteration.

\section*{Project Requirements and Roles}

Each team must include the following core components in their project:
%
\begin{itemize}
    \item \textbf{Path Planning}: Design algorithms for navigating the robot from one location to another, with or without a predefined map.
    \item \textbf{Sensing and Perception}: Use LIDAR, a camera color, and/or camera AprilTag vision to help the robot perceive its environment and make decisions in real time.
    \item \textbf{Control Systems}: The implement control loop to decide the values of Vref and Turn each 1ms in the robot’s \mintinline{c}{SWI1_HighestPriority} function. Vref and Turn are the inputs to the given PI speed controller of the robot.
\end{itemize}
%
Each component should have 1–2 members assigned.

\section*{Sample Project Idea}

An example project could involve \textbf{autonomous hallway navigation}, where your robot:
%
\begin{itemize}
    \item Follows hallway walls using sensor input.
    \item Avoids obstacles using LIDAR or vision.
    \item Collects small objects (e.g., golf balls) using the collection system from Lab 7.
    \item Returns autonomously to the starting point.
    \item Outputs live position and obstacle data to LabVIEW.
\end{itemize}

\section*{Sample Advanced Feature Ideas (Optional)}

Consider implementing creative or advanced features to enhance your project:
%
\begin{itemize}
    \item Improve localization by fusing LIDAR and camera data.
    \item Use A* path planning and adapt to newly discovered obstacles.
    \item Explore an entire hallway before returning to the start.
    \item Live obstacle mapping into LabVIEW, logging, and presentation of performance
    \item Trigger speech or audio responses (via LabVIEW or onboard) when people are detected.
    \item Use shape, color, and AprilTags to recognize specific objects (e.g., a trash can).
    \item Deliver objects to multiple pre-known locations with return to a loading zone between each delivery.
\end{itemize}
