\Ex[Drive RC Servos connected to the Robot]

Your instructor will take you through all the coding for this exercise. You will be using a new “Starter” project called “FinalProjectwithCANAprilStarter”. You will be using this project starter in Lab 7 also.

The robot car can connect and drive five RC Servos (we will probably not use more than two). Your instructor will show you where to connect the RC Servos and that they are driven with PWM outputs EPWM3A, EPWM3B, EPWM5A, EPWM5B and EPWM6A. Perform the following steps to have the robot drive RC Servos:
%
\begin{enumerate}
    \item In Timer2’s ISR, (which is called by default every 40ms.) Just call the function:
%
\begin{minted}{c}
PostSWI3();
\end{minted}
%
    {\itshape This will cause the \mintinline{c}{SWI3_LowestPriority} software interrupt to be called every 40ms. From here forward most of your code will need to be placed in the \mintinline{c}{SWI1_HighestPriority} function. You can also place less important code in the \mintinline{c}{SWI3_LowestPriority} function.}
    \item In \mintinline{c}{SWI3_LowestPriority}, first read the value of the encWheel:
%
\begin{minted}{c}
RCangle = readEncWheel();
\end{minted}
%
    Then call the five RC servo functions and pass \mintinline{c}{RCangle} to each of them:
%
\begin{minted}{c}
setEPWM3A_RCServo(RCangle) //RCangle is a value from -90 to 90
setEPWM3B_RCServo(RCangle) //RCangle is a value from -90 to 90
setEPWM5A_RCServo(RCangle) //RCangle is a value from -90 to 90
setEPWM5B_RCServo(RCangle) //RCangle is a value from -90 to 90
setEPWM6A_RCServo(RCangle) //RCangle is a value from -90 to 90
\end{minted}
%
    \item Then print the value of \mintinline{c}{RCangle} to the robot’s text LCD screen. Run your code. Now by spinning the encoder wheel in your hand, you can watch the text LCD screen and dial in the angle that moves the RC servos to certain angles.
%
    \begin{checkoff}[All five RC servo connections]
    \textbf{Show this code working to your Instructor and test that all 5 RC Servo connections work.}
    \end{checkoff}
\end{enumerate}
