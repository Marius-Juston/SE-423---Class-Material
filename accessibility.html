Accessibility

Statement

The SE 423 course material aims to meet WCAG 2.2 level AA, and PDF/UA-2 for documents. Everything is set in Atkinson Hyperlegible Next. Each handout is available as a tagged PDF, an accessible HTML page (equations as MathML), an EPUB 3 book and a large-print PDF; each lecture deck as a tagged PDF, the PowerPoint file and a text version with one section per slide. The web pages work by keyboard alone and in light and dark mode.

Every change is checked automatically (below). Some material still has known problems, listed here until they are fixed; new problems are not accepted.

Need something in another format, or found a barrier? Report it on GitHub or tell the course staff.
