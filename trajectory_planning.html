A* Search

Finds shortest path using f(n)=g(n)+h(n).

f(n) = g(n) + h(n) g = cost-so-far, h = heuristic

4-conn: Cardinal moves. Axis-aligned.

8-conn: +Diagonals (√2 cost).

Turn-and-Drive: State=(x,y,θ). Penalizes heading changes — better for diff-drive.

Hybrid A*

Expands via kinematically feasible arcs from pose (x,y,θ).

x' = x + v·cos(θ)·Δt y' = y + v·sin(θ)·Δt θ' = θ + ω·Δt

Multiple ω ∈ [-ω_max, ω_max]. Grid-binned closed set.

Analytic Expansion: Every N nodes, try Reeds-Shepp to goal. If collision-free → done instantly!

Lyapunov Controller

eₓ = cos(θ)·Δx + sin(θ)·Δy eᵧ = -sin(θ)·Δx + cos(θ)·Δy v = v_ref·cos(eθ) + Kx·eₓ ω = v_ref·(Ky·eᵧ + Kθ·sin(eθ))

Kx→longitudinal Ky→lateral Kθ→heading

Diff-Drive Kinematics

ẋ = v·cos(θ) ẏ = v·sin(θ) θ̇ = ω

Nonholonomic: cannot move sideways. Can spin in place or drive straight.

Dubins Curves

Shortest path for a forward-only vehicle with bounded turning radius. Exactly 6 types:

LSL LSR RSL RSR RLR LRL L=Left arc R=Right arc S=Straight

We compute all 6 and pick the shortest valid one.

Reeds-Shepp Curves

Extends Dubins by allowing reverse driving. Produces shorter paths.

Example: Lf-Rb-Lf (fwd-Left, back-Right, fwd-Left)

Green=forward Red=reverse

Used for analytic expansion in Hybrid A*.

Turning Circles

At any pose, the robot can turn left or right with minimum radius r. This creates two tangent circles per pose — the building blocks of all Dubins/RS paths.

Quintic polynomial — smooth acceleration profile

Why Polynomials?

Represent trajectories as continuous functions. Motors need smooth profiles — no instantaneous jumps in velocity or torque.

Cubic (3rd order)

x(t) = c₀ + c₁t + c₂t² + c₃t³

4 coefficients → constrains position & velocity at endpoints. Cannot constrain acceleration.

Quintic (5th order)

x(t) = c₀+c₁t+c₂t²+c₃t³+c₄t⁴+c₅t⁵

6 coefficients → constrains position, velocity, and acceleration. Guarantees smooth acceleration.

Motor Limits

Max RPM → v_max. Limited torque → a_max.

Red shading = limit violations. Try increasing T or reducing endpoint constraints.

Jerk Minimization (QP)

min J = ∫₀ᵀ ‖x⃛(t)‖² dt

Minimizing jerk → smoothest trajectories. Solvable as QP in milliseconds on MCUs.

Time-Elastic Bands

TEB treats the path as a rubber band between start and goal, optimized by gradient descent.

Obstacle Repulsion

F_obs ∝ 1/d² (repulsive)

Pushes band away from obstacles. Force ∝ inverse square distance.

Smoothness

F_sm ∝ -(pᵢ₋₁ - 2pᵢ + pᵢ₊₁)

Minimizes curvature — internal rubber band tension.

Kinematic Limits

Max velocity: limits spacing.

Min turn radius: prevents infeasible curvature.

These keep the band physically viable for the diff-drive robot.
